Nhiệm vụ 1.2: Cấu hình phần mềm cơ bản

Bước 1: Tải và cài đặt Notepad++

1. Truy cập trang chủ notepad-plus-plus.org và vào mục Downloads.

2. Chọn phiên bản mới nhất (ưu tiên bản Installer 64-bit cho Windows 10).

3. Mở file .exe vừa tải về, chọn English (hoặc Tiếng Việt)  Nhấn Next  I Agree Next theo mặc định để hoàn thành cài đặt.

Bước 2: Cài đặt Python và thêm PATH

1.Truy cập python.org/downloads/ và tải bản Python mới nhất.

2.Chạy file cài đặt, tích chọn vào ô "Add python.exe to PATH" ở ngay màn hình đầu tiên (nếu bỏ qua ô này, Notepad++ sẽ không tìm thấy Python).

3.Nhấn Install Now để hoàn tất.

Bước 3: Cấu hình phím tắt chạy Python trực tiếp

1. Mở Notepad++, chọn Run trên thanh menu -> chọn Run... (hoặc ấn phím F5).

2. Nhập chính xác đoạn lệnh sau vào ô trống: cmd /k python "$(FULL_CURRENT_PATH)"

3. Nhấn Save..., đặt tên cho phím tắt (ví dụ: Run Python) và chọn tổ hợp phím tắt thuận tiện (ví dụ: F5 hoặc Ctrl + F5). Bấm OK.

Bước 4: Thử nghiệm chương trình đầu tiên:

1.Tạo một file mới trong Notepad++, lưu lại với tên test.py (đảm bảo đuôi file là .py).

2.Soạn thảo dòng lệnh: print("Hello, Python!")

3.Cửa sổ Command Prompt sẽ bật lên và hiển thị kết quả.
